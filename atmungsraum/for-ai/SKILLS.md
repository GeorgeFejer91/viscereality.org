# Skill routes

## Always, in order

1. `for-ai` (installed personal skill): maintain this small control plane alongside
   the implementation. This is a subproject of an existing repository; do not run
   the new-repository bootstrap or create another GitHub repository.
2. `ponytail` (installed personal skill): choose the smallest complete change and
   avoid speculative scaffolding or dependencies.

## Conditional

- Before HTML UI design or editing, read `uncodixfy-pretext` and its
  `references/pretext.md`. Source:
  <https://github.com/GeorgeFejer91/uncodixfy-pretext>.
- If visible text or bounded controls are introduced, follow that skill's locked
  Pretext dependency, actual measurement, accessible no-fit behavior, and rendered
  verification. The current empty page has no text regions to measure.
- Native app skills do not apply to this static web subpage unless the requested
  target changes.

Use installed skills; do not fetch and execute unreviewed remote skill code.
